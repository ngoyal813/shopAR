🛍️ shopAR: Augmented Reality E-Commerce for AndroidshopAR is an innovative Android mobile application that redefines online shopping by integrating Augmented Reality (AR). Developed using Java and Google's ARCore library, this app allows users to accurately preview and interact with 3D models of products directly within their physical environment before making a purchase.✨ FeaturesThis application delivers a comprehensive and modern e-commerce solution:1. Immersive AR ShoppingReal-time Visualization: Users can place 3D product models (like furniture, accessories, or appliances) directly onto real-world surfaces using their device's camera.Scale and Fit Check: Allows customers to verify the size, fit, and aesthetic compatibility of a product with their home or surroundings.2. Full E-Commerce FunctionalityProduct Catalog: Browse and view detailed information for all available items.Secure Authentication: User registration and login system for a personalized shopping experience and order tracking.Cart and Checkout: Standardized workflow for adding items to the cart and completing the purchase.3. Inventory Management (Admin Panel)Dedicated Admin Login: A separate, secure login system for store managers.Product Management: Tools to easily add new products, upload 3D models, and update item details.Inventory Control: Functionality to monitor and manage stock levels in real time.💻 Technology StackCategoryTechnologyDescriptionMobile PlatformJava (Android)Core development language for the native Android application.Augmented RealityARCore (by Google)Provides the framework for motion tracking and environmental understanding required for stable AR object placement.Backend/DatabaseFirebase FirestorePrimary database for storing structured data (products, user profiles, orders).Real-time DataFirebase Realtime DBUsed for managing data that requires instantaneous synchronization, such as certain aspects of inventory or live feature updates.HostingGoogle FirebaseComprehensive cloud platform for authentication, data storage, and backend logic.📸 Visual ShowcaseTo truly showcase the power of AR in e-commerce, explore the following images demonstrating the user experience and administrative capabilities:AR Shopping Experience (Images 1 - 5)[Image showing the product detail view with the AR button highlighted][Image showing the object being manipulated/rotated in the AR view][Image showing the AR view on a different product, e.g., a lamp]User E-Commerce Flow (Images 6 - 10)ShutterstockAdmin Management Panel (Images 11 - 15)[Image showing the option to update stock/inventory of an item]🚀 Getting StartedTo set up and run the shopAR application locally, follow these steps:PrerequisitesAndroid Studio installed on your system.An Android device or emulator supporting ARCore.A Firebase Project set up to host the backend services (Firestore and Realtime DB).Installation and SetupClone the repository:Bashgit clone https://github.com/ngoyal813/shopAR.git
